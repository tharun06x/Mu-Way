# 🚀 ICRS — Intelligent Career Roadmap System

Personalised learning paths powered by ML, built on Mulearn's task ecosystem.

## Features
- AI-driven task recommendations based on your skill gaps
- 19 career roles supported (AI/ML Engineer, Backend Developer, etc.)
- Week-by-week roadmap with difficulty progression
- Rule-based fallback when ML model is unavailable

## Usage
Enter your **MUID**, **name**, and **dream role** in the sidebar → click **Generate Roadmap**.

## Stack
`Streamlit` · `scikit-learn` · `pandas` · `PyYAML`
